## 第 7 張 — LLM Serving: Heterogeneous GPU & Memory

目標時間：65 秒。

口述：

我現在的研究是：在算力不同、記憶體是 HBM、HBF，或兩者混合的 GPU 上，做考慮能耗的 LLM serving。

Serving 不是一種負載。Prefill 偏計算，decode 對記憶體頻寬比較敏感。模型權重大、以讀為主。KV cache 對延遲敏感，而且會一直更新。

未來的叢集可能同時有高算力和低算力的 GPU，記憶體也可能是 HBM-only、以 HBF 為主，或混合。這六格是模擬用的組態剖面，不是六款已經在賣的 GPU。

HBF 可以換到更大的容量，但延遲、頻寬、功耗和耐久性不一樣。以 HBF 為主的組態，可能需要緩衝和比較明確的資料管理。

所以研究問題是：request 應該怎麼排到這些特性不同的 GPU 上。

技術重點：

- 藍色是 HBM，綠色是 HBF，混合格是兩邊各一半。
- 問題是排程，不是封裝。
- 「可能」要留住。不要說未來叢集一定會這樣做。

注意事項：

- 不要說 HBF 硬體我已經量過。參數來自公開的 device model。
- 不要說這個問題從來沒有人做過。文獻裡已有 heterogeneous serving 和 HBF 的相關工作。我的研究是把它放成一個系統級的排程和能耗問題。
- 不要講 TSV、NAND、interposer。若對方一直問，一句話帶到「那是元件和封裝文獻，我的目標是 serving 排程」，然後回到矩陣。
- 另一份技術簡報引用過文獻模型（Li et al., arXiv:2608.11668）。那是文獻，不是我們的量測，也不要在這 70 秒裡打開。

可能的問題：

- 「HBF 和 HBM 差在哪？」容量更高，延遲、頻寬、功耗、耐久性的取捨不同。HBF-dominant 可能要緩衝。不展開製程。
- 「你要排的是什麼？」LLM request。考量 prefill/decode、權重和 KV cache 對計算與記憶體的不同需求，以及這六種剖面的差異。策略本身還沒做成結果，那是下一步。

## 第 8 張 — Research Methodology: Simulation Framework

目標時間：85 秒。這是 LLM 段的主投影片。

口述：

這是計畫中的系統級模擬，不是已經接好、也不是已經驗證過的系統。

步驟 1，真實 GPU profiling：計算延遲、GPU 功耗、記憶體用量，以及隨 workload 改變的效能。步驟 2，HBF 的裝置模型：容量、讀寫延遲、有效頻寬、資源競爭，還有能耗。這部分用公開參數和模擬器，不是我手上有一顆 HBF 在量。

步驟 3 把兩邊收成一個 serving 模型：workload trace、異質 GPU 剖面、request routing、batching 和 scheduling、記憶體服務，以及效能和能耗的估計。步驟 4 的輸出是估計值：吞吐、TTFT、TPOT、SLO goodput、每 token 能耗、峰值功耗。

TTFT 是時間到第一個 token。TPOT 是每個輸出 token 的時間。SLO goodput 是有達到延遲目標的有效請求。

候選框架是 LLMServingSim 2.0 和 FlashLab HBFSim，還在評估，沒有接進同一個系統。研究目標是系統級的路由、排程和能耗。不是 GPU instruction 等級的 cycle simulation。不過會影響結果的 memory-service dependency 和 contention 仍然要留在模型裡。

技術重點：

- 四個編號就是工作流程：profile、model HBF、整合剖面、評估取捨。
- 左上是量測或可重用的 GPU 資料，左下是模型，不要講成同一種證據。
- 右邊寫 Estimated outputs，口頭也要說「估計」。

注意事項：

- 不要說模擬器已經實作或已經校正。
- 不要說兩個開源專案已經整合。
- 不要放任何加速比或能耗下降的數字。
- 框架網址，被問再給：
  - https://github.com/casys-kaist/LLMServingSim
  - https://github.com/FlashLabAE/HBFSim

可能的問題：

- 「為什麼不用 cycle-accurate simulator？」因為決策在 request 怎麼路由、怎麼排、效能和能耗如何取捨。Cycle simulation 太細，也答不了這個排程問題。會影響服務時間的記憶體競爭還是要建模。
- 「資料從哪來？」GPU 計算和功耗來自真實 profiling，或重用可信的 profiling。HBF 來自公開 device 參數和 HBF 模擬器。兩類來源在圖上是分開的。
